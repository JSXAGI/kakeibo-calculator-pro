# 🧮 家計簿電卓 Pro (Kakeibo Calculator Pro)

「計算する」と「記録する」を一つに融合させた、直感的なPWA対応の家計簿アプリです。
ブラウザ上で動作し、インストールすればネイティブアプリのようにオフラインでも使用可能です。

ユーザーがデータの保存場所（ブラウザ依存）に迷わないよう、アプリ自身が状態を判別して案内する「超親切設計」を搭載しています。

## ✨ 主な機能 (Features)

* **電卓と家計簿のシームレスな統合**: 金額を計算し、そのまま「収入」「支出」として記録できます。
* **実務電卓レイアウト**: 「＋」と「＝」ボタンを縦2マスに配置し、ブラインドタッチに近い操作性を実現。
* **スマホ特化のUI**: 連打時の画面ズーム防止機能を実装済み。ストレスフリーな入力が可能です。
* **自動計算と色分け表示**: 収入（プラス・青）と支出（マイナス・赤）を自動判別し、収支合計を即座に算出します。
* **自由なカテゴリー入力**: プリセットの分類（食費、住居費など）に加え、独自の項目を自由に入力可能。
* **PWA完全対応**: iOS / Android 共に「ホーム画面に追加」でオフラインアプリとして動作します。
* **【NEW】ユーザー迷子防止ナビ**: 
  現在の起動状態（ブラウザ閲覧か、アプリ起動か）をJavaScriptが自動判別。「ブラウザの履歴削除でデータが消えるリスク」を事前に防ぐための案内板を画面内に標準装備しています。
  
  2026.06.09
  【NEW】安全なバックアップ機能: 記録したデータをいつでもボタン1つでテキストファイル（.txt）として端末に保存可能。機種変更時やブラウザの履歴削除時も、データを安全に持ち運べます。

## 🚀 使い方 (How to Use)

1. **計算する**: 電卓エリアで金額を計算します（例: `500 * 3`）。
2. **分類を選ぶ**: 「収入💰」か「支出🏠」を選び、カテゴリーを選択（または独自項目を入力）します。
3. **記録する**: 「記録する」ボタンを押すと履歴に追加され、電卓が自動的にクリアされます。
4. **修正する**: 誤って記録した場合は、履歴リスト右側の「×」ボタンで即座に削除できます。
5. **アプリ化する**: 画面下の「ブラウザ閲覧モード」という警告が出ている場合は、BraveやFirefoxなどのセキュアなブラウザのメニューから「ホーム画面に追加」を行ってください。表示が「アプリモード動作中（緑）」に変われば、データは100%安全に保護されます。

## 🛠 技術スタック (Tech Stack)

* HTML5 / CSS3 (CSS Grid によるレスポンシブデザイン)
* Vanilla JavaScript (依存ライブラリなし / 動的PWAモード判定ロジック搭載)
* LocalStorage API (ブラウザごとの独立データ保存)
* Service Worker & Web App Manifest (PWA対応)

## 📂 インストール・デプロイ方法 (Setup)

本リポジトリのファイルを同一ディレクトリに配置し、Webサーバー（GitHub Pages等）でホスティングするだけで動作します。複雑なビルド環境（Node.jsなど）は一切不要です。

* `index.html` （アプリ本体・UI・状態判別ロジック）
* `manifest.json` （PWAのインストール設定・アプリ情報）
* `sw.js` （オフライン動作を制御するサービスワーカー）
* `icon-192.png` / `icon-512.png` （ホーム画面用のアイコン画像）

**【GitHub Pagesで公開する場合】**
このリポジトリをFork、または自身の作成したリポジトリにプッシュし、[Settings] > [Pages] からブランチを `main` に指定して保存するだけで、あなた専用のセキュアな家計簿アプリが世界に公開されます。
